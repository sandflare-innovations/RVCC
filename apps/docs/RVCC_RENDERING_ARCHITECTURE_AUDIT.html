3 Security, Scalability & Architecture Matrix
🔒 Security & Data Integrity
Defense-in-Depth
  • Dual Schema Sanitization: Form payloads are validated client-side for UX and re-validated on Cloudflare Workers before database writes.
  • Role-Based Access Control (RBAC): Staff roles (SUPER_ADMIN, ADMIN, REVIEWER) and rank calculations are encapsulated in @rvcc/types.
  • Isolated Deployment Boundaries: Staff backoffice logic never bundles into public client scripts.
⚡ Scalability & Performance
Edge Optimized
  • Zero-Schema Drift: Updates to validation rules propagate instantaneously to all apps via pnpm workspace packages.
  • Zero-Egress Storage: Large compliance documents & PDFs are uploaded directly to Cloudflare R2 via presigned URLs.
  • Typecheck Certification: Monorepo compiles cleanly with 0 TypeScript errors across all 4 applications.
